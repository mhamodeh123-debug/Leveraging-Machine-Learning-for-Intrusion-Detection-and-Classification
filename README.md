# Leveraging-Machine-Learning-for-Intrusion-Detection-and-Classification
This work describes a performance for seven
supervised machine learning algorithms on intrusion detection on
the ToN-IoT Train/Test Network dataset. After removing
duplicates and nominal attribute encoding, traditional classifiers
(Naive Bayesian, Logistic Regression, Decision Trees, RF, and
RBF SVM) and ensemble models (Bagging, AdaBoost) were
compared for intrusion detection performance on a stratified
75/25 split of the dataset, showing that AdaBoost had 100%
accuracy, precision, recall, and F1-score on this task, with
Decision Trees and RF classifiers also performing very closely.
